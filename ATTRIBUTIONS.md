# Banner artwork

`assets/olympic-village.png` is a pixel-art adaptation generated with the built-in ImageGen tool, using [BC Place by Alexis Birkill](https://photovancouver.com/photos/bc-place) as the visual reference for an actual Olympic Village viewpoint.

The source photograph is by Alexis Birkill and is not included in this repository. The illustration preserves the reference's general landmark arrangement and ferry-dock foreground; it is an artistic rendering, not a survey or a current photograph.
